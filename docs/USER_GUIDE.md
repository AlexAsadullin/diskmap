# Руководство пользователя DiskMap

Это руководство объясняет, куда нажимать, чтобы найти, что занимает место на диске, и освободить его.
Названия кнопок даны по-русски, в скобках — как они называются в английском интерфейсе.

## 1. Установка и первый запуск

1. Скачайте **[DiskMap.zip](https://github.com/AlexAsadullin/diskmap/releases/latest/download/DiskMap.zip)**, откройте его двойным щелчком и перетащите **DiskMap.app** в папку **Программы**. (Есть и образ диска: [DiskMap.dmg](https://github.com/AlexAsadullin/diskmap/releases/latest/download/DiskMap.dmg).)
2. Запустите DiskMap из Программ. Приложение не нотаризовано Apple, поэтому в первый раз macOS попросит разрешения:
   - **macOS 15 и новее:** в окне предупреждения нажмите **Готово**, затем **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **Всё равно открыть** рядом с DiskMap и подтвердите паролем;
   - **macOS 13–14:** щёлкните по приложению **правой кнопкой → Открыть → Открыть**.

   Это нужно сделать только один раз.
3. Чтобы приложение видело все папки (Почту, Сообщения, данные других программ), выдайте ему **Полный доступ к диску**:
   - на стартовом экране нажмите ссылку **«Полный доступ к диску…»** (или меню **DiskMap → Полный доступ к диску…**);
   - в открывшихся Системных настройках включите переключатель напротив **DiskMap**;
   - перезапустите DiskMap.

   Без этого доступа приложение всё равно работает, но недоступные папки будут показаны серыми блоками «Нет доступа».

## 2. Запуск сканирования

На стартовом экране есть большие кнопки:

| Кнопка | Что сканирует |
| --- | --- |
| **Домашняя папка** (Home Folder) | Вашу папку пользователя `~` |
| **Том «Macintosh HD»** и другие тома | Весь диск целиком, включая свободное место |
| **Выбрать папку…** (Choose Folder…) | Любую папку по вашему выбору |
| **Открыть результат…** (Open Result…) | Ранее сохранённый файл `.diskmap` |

Другие способы:
- перетащите папку или диск из Finder **в окно** DiskMap или **на иконку DiskMap в Dock**;
- кнопка **Сканировать** (Scan) слева на панели инструментов или **⌘N**;
- в Терминале: `diskmap ~/Downloads`.

Во время сканирования видны полоса прогресса, текущая папка, число файлов и найденный объём. Кнопка **Отменить** (Cancel) останавливает сканирование.

Каждое новое сканирование открывается в отдельной вкладке. Вкладки можно отключить в **DiskMap → Настройки… → Основные**.

├──────────────────────────────────────────────────────────────────────────────┤

│          (прямоугольники = файлы и папки)                │  имя, размер,     │

## 4. Как читать карту

- **Площадь прямоугольника = размер.** Файл в 2 ГБ занимает вдвое больше места на карте, чем файл в 1 ГБ. Самое крупное всегда в левом верхнем углу.
- **Рамка = папка.** Всё, что внутри рамки, лежит в этой папке. У папок первых двух уровней сверху есть полоска с именем и размером.
- **Цвет = категория папки**, в которой лежит файл:

  | Цвет | Категория |
  | --- | --- |
  | 🟥 красный | Приложения (`/Applications`) |
  | 🟦 синий | Фильмы (`~/Movies`) |
  | 🟪 фиолетовый | Музыка |
  | розовый | Фото и изображения |
  | 🟩 зелёный | Документы |
  | бирюзовый | Рабочий стол |
  | 🟧 оранжевый | Загрузки |
  | голубой | iCloud Drive |
  | 🟨 жёлтый | Данные приложений и кэши (`~/Library`) |
  | лаймовый | Разработка (`.git`, `node_modules`, DerivedData) |
  | тёмно-серый | Система — **удалить нельзя** |
  | коричневый | Корзина |
  | светло-серый | Прочее |

- **Серый блок «Мелкие файлы (N шт., X МБ)»** — файлы, слишком маленькие, чтобы нарисовать их по отдельности. Приблизьте карту, и они разойдутся на отдельные прямоугольники.
- **Серый заштрихованный блок «Нет доступа»** — папка, которую macOS не дала прочитать (см. раздел 1, п. 3).
- **При сканировании всего диска** в карте есть блоки **Свободно**, **Очищаемое (purgeable)** и **Снимки и служебные тома** — это не файлы, их нельзя удалить; вместе со всеми файлами они дают полную ёмкость диска.

## 5. Мышь на карте

| Действие | Результат |
| --- | --- |
| **Навести курсор** | Подсказка: имя, размер, категория, уровень от корня, полный путь. Тонкими линиями обводятся все родительские папки |
| **Щелчок** | Выделить. Подробности появляются в инспекторе справа |
| **⌘ + щелчок** | Добавить или убрать элемент из выделения (для удаления нескольких сразу) |
| **Двойной щелчок по папке** | Войти в папку: она разворачивается на всю карту |
| **Правый щелчок** | Меню: Приблизить, Показать в Finder, Быстрый просмотр, Скопировать путь, Пересканировать, В корзину |

## 6. Перемещение по папкам

| Задача | Куда нажать | Клавиши |
| --- | --- | --- |
| Войти в папку | Двойной щелчок по ней или кнопка **⤡** на панели | ⌘↓ |
| Выйти на уровень вверх | Кнопка **↑** на панели | ⌘↑ |
| Вернуться к началу | Первый сегмент строки пути | ⌘⇧↑ |
| Перейти на любой уровень пути | Щёлкнуть нужное имя в **строке пути** | — |
| Назад / вперёд по истории | Кнопка **‹** на панели, свайп двумя пальцами по трекпаду | ⌘[ / ⌘] |

## 7. Увеличение карты

Увеличение показывает мелкие файлы в выбранном месте, не меняя папку.

| Задача | Как |
| --- | --- |
| Увеличить / уменьшить | Кнопки **⊕** / **⊖** на панели, щипок на трекпаде, ⌘ + колесо мыши, ⌘+ / ⌘− |
| Двигать увеличенную карту | Прокрутка двумя пальцами, или зажать **Пробел** и тянуть мышью, или щёлкнуть по **мини-карте** в правом нижнем углу |
| Вернуть исходный масштаб | ⌘0, или двойное касание двумя пальцами |

Текущий масштаб виден в строке состояния («Масштаб ×4.0»).

## 8. Глубина: сколько уровней показывать

Ползунок **Глубина** (Depth) на панели инструментов:
- **Все** (по умолчанию) — видны все вложенные файлы;
- **1** — только папки первого уровня, каждая одним сплошным блоком. Удобно для общей картины: «что больше — Library или Movies?»;
- 2, 3, … — больше деталей.

Расположение блоков при смене глубины не меняется — меняется только детализация.
Клавиши: ⌥1 … ⌥9, ⌥0 — все уровни.

## 9. Инспектор (правая панель)

Показать или скрыть: **⌘I** или меню **Вид → Показать инспектор**.

**Вкладка «Сведения»** (Info) для выделенного элемента:
- имя, полный путь (можно выделить и скопировать);
- физический размер (место на диске) и логический (размер содержимого);
- доля от корня, категория, дата изменения, число файлов;
- сколько файлов выгружено в iCloud;
- кнопки **Показать в Finder** и **В корзину**;
- список **20 крупнейших файлов внутри** — щёлкните строку, чтобы показать файл на карте.

**Вкладка «Дерево»** (Tree) — те же данные списком папок, отсортированных по размеру:
- треугольник раскрывает папку;
- щелчок по строке выделяет элемент на карте (и наоборот);
- флажок слева добавляет элемент к выделению — так удобно отметить несколько файлов для удаления;
- двойной щелчок входит в папку.

## 10. Легенда (нижняя строка)

Показать или скрыть: **⌘L**.
- **Наведите** на категорию — её файлы подсветятся на карте, остальное потускнеет.
- **Щёлкните** по категории — она скроется с карты (щёлкните ещё раз, чтобы вернуть).
- Рядом с каждой категорией — её общий объём.

## 11. Поиск по имени

1. Щёлкните поле **Поиск по имени** справа на панели (или **⌘F**).
2. Введите часть имени, например `.dmg` или `node_modules`.
3. Найденное подсвечивается на карте, всё остальное тускнеет. Список найденного — в инспекторе, по убыванию размера; щёлкните строку, чтобы перейти к файлу.
4. **Enter** — перейти к самому крупному совпадению. **Esc** на карте или крестик в поле — сбросить поиск.

## 12. Удаление файлов

1. Выделите файл или папку щелчком (несколько — **⌘ + щелчок** или флажками во вкладке «Дерево»).
2. Нажмите **В корзину** (Move to Trash) на панели инструментов, или в инспекторе, или в меню правого щелчка, или **⌘⌫**.
3. В окне подтверждения проверьте список, общий объём и число файлов. Нажмите **В корзину**.
4. Блок исчезнет с карты, размеры родительских папок сразу уменьшатся, в строке состояния появится **«Освобождено: X ГБ»**.

**Передумали?** **⌘Z** (меню **Правка → Отменить**) вернёт файлы из Корзины на прежнее место.

Полезно знать:
- Элементы категории **«Система»** удалить нельзя — кнопка неактивна, причина написана в подсказке.
- При удалении из `~/Library` или `/Library` приложение предупредит, что это данные программ: их удаление может сбросить настройки.
- После удаления программы из «Программ» DiskMap предложит отметить её оставшиеся данные в `~/Library` (кэши, настройки, контейнеры).
- Окно подтверждения для Корзины можно отключить флажком «Больше не спрашивать» (вернуть — в Настройках).
- **Удаление навсегда, мимо Корзины** выключено по умолчанию. Включается в **Настройки → Основные**, после чего работает **⌘⌥⌫**. Оно всегда спрашивает подтверждение и не отменяется.
- Все удаления записываются в журнал: меню **Правка → Журнал удалений**.

## 13. Сохранение, сравнение, экспорт

| Задача | Где |
| --- | --- |
| Сохранить результат сканирования | **Файл → Сохранить результат сканирования…** (⌘S) |
| Открыть сохранённый результат (например, чтобы сравнить «до» и «после» в соседних вкладках) | **Файл → Открыть результат сканирования…** (⌘O) или двойной щелчок по файлу `.diskmap` |
| Сохранить картинку карты или таблицу | **Файл → Экспорт…** (⌘⇧E), внизу окна сохранения выберите **PNG** или **CSV** |
| Пересканировать выбранную папку после изменений | **Файл → Пересканировать** (⌘R) или правый щелчок → **Пересканировать** |

## 14. Физический и логический размер

По умолчанию показывается **физический** размер — сколько места файл реально занимает на диске (совпадает с `du`). **Логический** — сколько байт в содержимом файла; для сжатых, разрежённых файлов и файлов iCloud он отличается.

Переключение: щёлкните **«Размер: физический»** в строке состояния или **⌘⇧P**. Режим по умолчанию задаётся в Настройках.

## 15. Настройки

**DiskMap → Настройки…** (⌘,):
- **Основные:** язык интерфейса (русский / английский), размер по умолчанию, вкладки, подтверждение Корзины, окончательное удаление.
- **Категории:** щёлкните цветной квадрат, чтобы сменить цвет категории (если цвет уже занят, появится предупреждение). Кнопка **Добавить категорию** создаёт свою: укажите имя, шаблон (`Steam*` — имя папки, `~/Projects` — путь) и цвет.

## 16. Командная строка

```sh
diskmap ~/Downloads                         # открыть DiskMap и просканировать папку
diskmap --csv ~ --depth 2 > home.csv        # таблица без интерфейса
diskmap --help                              # все параметры
```
