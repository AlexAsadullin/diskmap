# ТЗ: визуализатор занятости диска для macOS

Oct 20, 2026 · @Alex

## 1. Цель проекта

Разработать нативное приложение для macOS, которое за один взгляд показывает, что именно занимает место на диске, и позволяет сразу его освободить. Диск отображается картой прямоугольников (treemap), где площадь прямоугольника пропорциональна размеру файла, а цвет обозначает категорию папки, где лежит файл.

Решаемая проблема:

- Встроенные средства macOS (Finder, «Хранилище» в настройках) показывают логический размер файлов и завышают папки с файлами iCloud, APFS-клонами и разрежёнными файлами.
- Крупные скрытые потребители места (образы ВМ, кэши, данные в \~/Library) прячутся в «Системных данных» и не видны пользователю.
- Списочные утилиты требуют последовательно раскрывать папки и не дают общей картины.

Результат: пользователь за 1–2 минуты находит самые крупные файлы и папки, понимает, к какой категории они относятся, и удаляет ненужное, не выходя из приложения.

## 2. Платформа и термины

Приложение для macOS 13 и новее, универсальная сборка (Apple Silicon и Intel), язык Swift, интерфейс на SwiftUI, отрисовка карты через Core Animation или Metal. Распространение вне Mac App Store (подписанный и нотаризованный .dmg), потому что песочница App Store не даёт сканировать весь диск.

| Термин | Значение |
| --- | --- |
| Карта (treemap) | Прямоугольная область, разбитая на вложенные прямоугольники папок и файлов |
| Корень | Папка или том, выбранные для сканирования |
| Глубина | Число уровней вложенности от корня (корень = 0) |
| Логический размер | Размер файла как его видит приложение (число байт в содержимом) |
| Физический размер | Место, реально занятое на диске (выделенные блоки) |
| Категория | Тип папки верхнего уровня, определяющий цвет (см. раздел 6) |

## 3. Сканирование и подсчёт размера

По умолчанию размер считается как физический, чтобы цифры совпадали с реально занятым местом, как у `du` в Linux.

1. Пользователь выбирает корень: том, домашнюю папку или любую папку (диалог выбора или перетаскивание на окно или иконку в Dock).
2. Сканер обходит дерево в несколько потоков (getattrlistbulk), не выходя за пределы тома и не следуя символическим ссылкам.
3. Жёсткие ссылки учитываются один раз (по иноду).
4. Файлы iCloud, выгруженные в облако (dataless), имеют физический размер 0 и помечаются отдельно; сканер не должен инициировать их скачивание.
5. Папки без доступа показываются серым прямоугольником «Нет доступа»; при первом таком случае приложение предлагает выдать Полный доступ к диску и открывает нужный раздел настроек.
6. Во время сканирования показываются прогресс, текущая папка, число файлов и накопленный объём; сканирование можно отменить.

Дополнительно при сканировании целого тома показываются отдельными блоками: свободное место, purgeable-пространство и локальные снимки Time Machine (по данным `tmutil` и API тома), чтобы сумма блоков равнялась ёмкости диска.

Результат сканирования можно сохранить в файл и открыть позже для сравнения.

## 4. Интерфейс

Главное окно состоит из пяти областей; карта занимает не менее 70% площади окна. Каждое сканирование открывается в своём окне или вкладке.

| Область | Расположение | Содержимое |
| --- | --- | --- |
| Панель инструментов | Верх окна | Кнопки «Сканировать», «Назад», «Вверх», «Приблизить», «Отдалить», «В корзину», ползунок глубины, поиск по имени |
| Строка пути («хлебные крошки») | Под панелью | Путь от корня до текущего вида; щелчок по сегменту переходит на этот уровень |
| Карта | Центр | Treemap текущей папки (разделы 5–8) |
| Инспектор | Правая боковая панель, скрываемая | Имя, полный путь, физический и логический размер, доля от корня в %, категория, дата изменения, число файлов (для папки), список 20 крупнейших вложенных элементов |
| Строка состояния и легенда | Низ окна | Объём корня, свободно на томе, текущий масштаб; легенда цветов с суммарным объёмом каждой категории |

Поведение курсора на карте:

- Наведение: прямоугольник подсвечивается рамкой, границы его родительских папок выделяются тонкими линиями, всплывает подсказка с именем, размером и путём.
- Одинарный щелчок: выделение, данные появляются в инспекторе.
- Двойной щелчок по папке: приближение к ней (раздел 8).
- Правый щелчок: контекстное меню (раздел 10).

Поддерживаются светлая и тёмная темы, русский и английский языки интерфейса.

## 5. Карта: размер прямоугольника = размер файла

Площадь каждого прямоугольника строго пропорциональна размеру файла: файл в 2 ГБ занимает вдвое больше площади, чем файл в 1 ГБ. Площадь папки равна сумме площадей её содержимого.

- Алгоритм раскладки: squarified treemap, чтобы прямоугольники были близки к квадратам и их легко сравнивать глазом.
- Элементы внутри папки раскладываются по убыванию размера, крупные в левом верхнем углу.
- Размер для раскладки по умолчанию физический; в настройках можно переключить на логический. Режим всегда показан в строке состояния.
- Папки обводятся рамкой, толщина которой уменьшается с глубиной; файлы заливаются цветом с лёгким градиентом (cushion shading), чтобы соседние файлы одного цвета различались.
- Подпись (имя и размер) выводится прямо в прямоугольнике, если он не меньше 80×24 pt.
- Файлы меньше 1 пикселя в текущем масштабе объединяются в серый блок «Мелкие файлы (N шт., X МБ)», чтобы их суммарный объём не терялся.
- При изменении размера окна карта перестраивается с сохранением пропорций.

## 6. Цвета: категория папки, а не случайность

Цвет прямоугольника обозначает категорию папки, в которой лежит файл: красный — Applications, синий — Movies, для каждой другой категории свой цвет. Категория наследуется всеми вложенными файлами на любой глубине.

| Категория | Папки | Цвет | HEX |
| --- | --- | --- | --- |
| Приложения | /Applications, \~/Applications | Красный | #E5484D |
| Фильмы | \~/Movies | Синий | #3E63DD |
| Музыка | \~/Music | Фиолетовый | #8E4EC6 |
| Фото и изображения | \~/Pictures | Розовый | #D6409F |
| Документы | \~/Documents | Зелёный | #30A46C |
| Рабочий стол | \~/Desktop | Бирюзовый | #12A594 |
| Загрузки | \~/Downloads | Оранжевый | #F76B15 |
| iCloud Drive | \~/Library/Mobile Documents | Голубой | #0090FF |
| Данные приложений и кэши | \~/Library (кроме iCloud), /Library | Жёлтый | #FFC53D |
| Разработка | \~/Developer, папки с .git, node\_modules, Xcode DerivedData | Лаймовый | #7CB518 |
| Система | /System, /usr, /bin, /sbin, /private, /opt | Тёмно-серый | #60646C |
| Корзина | \~/.Trash | Коричневый | #A18072 |
| Прочее | Всё, что не попало в категории выше | Светло-серый | #B9BBC6 |

Правила:

1. Категория файла определяется по ближайшей вышестоящей папке из таблицы: файл в \~/Library/Mobile Documents — это iCloud, а не «Данные приложений». Правило «Разработка» срабатывает в любой категории (node\_modules внутри Documents красится лаймовым).
2. Пользователь может в настройках добавить свою категорию (путь или шаблон имени папки + цвет) и поменять цвет любой категории; приложение предупреждает, если выбранный цвет уже занят другой категорией.
3. При наведении на категорию в легенде все её файлы на карте подсвечиваются, остальные затемняются; щелчок по категории скрывает или показывает её.
4. Цвет не единственный носитель смысла: категория всегда пишется текстом в подсказке и инспекторе (для пользователей с нарушением цветовосприятия).

## 7. Группировка по папкам и уровни удалённости от корня

На карте видно, какие файлы объединены в одну папку: файлы одной папки всегда лежат плотно внутри её рамки, а уровень вложенности от корня регулируется ползунком глубины.

Ползунок «Глубина» (значения 1–10 и «Все», по умолчанию «Все»):

- При глубине N папки на уровне N отображаются одним сплошным прямоугольником с именем и суммарным размером, без разбивки на файлы. Пример: глубина 1 при корне \~ показывает только Documents, Movies, Library и т. д. как целые блоки.
- Размер блока свёрнутой папки точно равен сумме её содержимого, так что карта не меняет раскладку при смене глубины, меняется только детализация.
- Глубина считается от текущего вида: после приближения к папке её содержимое становится уровнем 1.

Визуальное разделение уровней:

- У каждой папки своя рамка и отступ внутрь (2 pt на уровень), поэтому вложенность читается как «коробки в коробках».
- У папок первых двух уровней над содержимым идёт полоска-заголовок с именем и размером.
- При наведении на файл вся цепочка родительских папок до корня обводится, а в подсказке указан уровень («Уровень 4 от корня»).

Альтернативное представление: в инспекторе есть вкладка «Дерево» — список папок с раскрытием и сортировкой по размеру, синхронизированный с картой (выделение в одном месте подсвечивает элемент в другом).

## 8. Приближение и отдаление

Предусмотрены два вида масштабирования: структурное (войти в папку или выйти из неё) и свободное (увеличение участка карты). Все переходы анимированы (200–300 мс), чтобы пользователь не терял ориентацию.

| Действие | Как вызвать | Результат |
| --- | --- | --- |
| Приблизить к папке | Двойной щелчок, Cmd+↓, кнопка «Приблизить» | Выбранная папка разворачивается на всю карту, путь добавляется в строку пути |
| Отдалить на уровень | Cmd+↑, кнопка «Вверх», щелчок по сегменту строки пути | Карта показывает родительскую папку, предыдущая папка остаётся выделенной |
| К корню | Cmd+Shift+↑ | Возврат к исходному виду |
| Назад / вперёд | Cmd+\[ / Cmd+\], свайп двумя пальцами | Переход по истории просмотра |
| Свободное увеличение | Pinch на трекпаде, Cmd+колесо мыши, Cmd+«+» | Карта увеличивается относительно точки под курсором, до ×64 |
| Свободное уменьшение | Pinch, Cmd+колесо, Cmd+«−» | Обратно до ×1 (вся текущая папка) |
| Перемещение увеличенной карты | Прокрутка двумя пальцами, перетаскивание с зажатым пробелом | Сдвиг видимой области |
| Сбросить масштаб | Cmd+0 | ×1, без смены текущей папки |

При свободном увеличении мелкие файлы, ранее свёрнутые в блок «Мелкие файлы», разворачиваются в отдельные прямоугольники, а подписи появляются по мере того, как блоки достигают минимального размера из раздела 5. Текущий масштаб виден в строке состояния, а в углу карты показывается мини-карта с рамкой видимой области.

## 9. Удаление файлов из интерфейса

Пользователь удаляет файлы и папки прямо с карты; по умолчанию они перемещаются в Корзину, а карта пересчитывается без повторного сканирования.

1. Выделение: щелчок, Cmd+щелчок для нескольких элементов, либо флажки во вкладке «Дерево».
2. Команда «В корзину» (Cmd+Backspace, кнопка на панели, контекстное меню).
3. Диалог подтверждения: список элементов, их суммарный объём и число файлов внутри папок. Диалог можно отключить для перемещения в Корзину, но не для окончательного удаления.
4. После удаления прямоугольник исчезает с анимацией, размеры всех родительских папок уменьшаются, в строке состояния показывается «Освобождено: X ГБ» (сумма за сеанс).
5. Отмена: Cmd+Z возвращает последние удалённые в Корзину элементы на исходное место.

Ограничения и защита:

- Окончательное удаление мимо Корзины (Cmd+Option+Backspace) включается в настройках и всегда требует подтверждения с предупреждением, что действие необратимо.
- Элементы категории «Система» и тома только для чтения удалить нельзя: команда неактивна, в подсказке причина.
- Для элементов из \~/Library и /Library диалог дополнительно предупреждает, что это данные приложений и их удаление может сбросить настройки или нарушить работу программы.
- Удаление приложения из /Applications предлагает заодно показать его данные в \~/Library (Application Support, Caches, Containers) для ручного выбора.
- Если файл открыт другим процессом или нет прав, показывается понятная ошибка; остальные выделенные элементы всё равно удаляются.
- Все удаления пишутся в журнал (дата, путь, размер, способ), доступный из меню.

## 10. Команды и горячие клавиши

Все команды доступны из строки меню; наиболее частые дублируются на панели инструментов и в контекстном меню.

| Меню | Команда | Клавиши |
| --- | --- | --- |
| Файл | Сканировать папку / том… | Cmd+N |
| Файл | Пересканировать текущую папку | Cmd+R |
| Файл | Открыть / сохранить результат сканирования | Cmd+O / Cmd+S |
| Файл | Экспорт карты в PNG, списка в CSV | Cmd+Shift+E |
| Правка | В корзину | Cmd+Backspace |
| Правка | Удалить навсегда (если включено) | Cmd+Option+Backspace |
| Правка | Отменить перемещение в корзину | Cmd+Z |
| Правка | Найти по имени | Cmd+F |
| Правка | Скопировать путь | Cmd+Option+C |
| Вид | Приблизить к папке / на уровень выше / к корню | Cmd+↓ / Cmd+↑ / Cmd+Shift+↑ |
| Вид | Увеличить / уменьшить / сбросить масштаб | Cmd+«+» / Cmd+«−» / Cmd+0 |
| Вид | Глубина 1–9 / все уровни | Option+1…9 / Option+0 |
| Вид | Показать инспектор / легенду | Cmd+I / Cmd+L |
| Вид | Размер: физический / логический | Cmd+Shift+P |

Контекстное меню на элементе карты: Приблизить, Показать в Finder, Быстрый просмотр, Скопировать путь, Пересканировать, В корзину.

Также предусмотреть консольный запуск: `diskmap <путь>` открывает приложение со сканированием этой папки, `diskmap --csv <путь>` выводит список без интерфейса.

## 11. Нефункциональные требования

| Требование | Значение |
| --- | --- |
| Скорость сканирования | Не медленнее `du -sk` на том же дереве; 1 млн файлов на SSD — до 60 с |
| Память | До 150 байт на файл, не более 1,5 ГБ на 5 млн файлов |
| Отрисовка | 60 кадров/с при масштабировании и наведении; пересчёт карты после удаления — до 100 мс |
| Точность | Расхождение с `du -skx` на той же папке не более 1% |
| Безопасность | Сканер только читает метаданные, не открывает содержимое файлов; никаких сетевых запросов и телеметрии |
| Права | Работа без root; полнота сканирования — через Полный доступ к диску |
| Доступность | VoiceOver зачитывает имя, размер и категорию элемента; навигация по карте стрелками |
| Совместимость | macOS 13+, APFS и HFS+, внешние диски и сетевые тома (SMB) |
| Лицензия | Бесплатно, исходный код открыт (MIT или GPL — уточнить) |

## 12. Критерии приёмки

- [ ] Суммарный размер \~/Documents в приложении совпадает с `du -skx ~/Documents` (расхождение не более 1%), в том числе при включённой синхронизации iCloud.
- [ ] Измерение площадей на скриншоте показывает, что отношение площадей двух файлов равно отношению их размеров (погрешность до 2% за счёт отступов и рамок).
- [ ] Файлы из /Applications красные, из \~/Movies синие, каждая категория из раздела 6 окрашена своим цветом; легенда показывает объём каждой категории.
- [ ] При глубине 1 видны только папки первого уровня; при увеличении глубины появляются вложенные уровни, раскладка папок не меняется.
- [ ] Приближение двойным щелчком, отдаление Cmd+↑ и свободное масштабирование жестом работают плавно, без рывков на дереве в 1 млн файлов.
- [ ] Файл, удалённый с карты, оказывается в Корзине, карта и размеры родительских папок обновляются сразу, Cmd+Z возвращает его на место.
- [ ] Элементы категории «Система» удалить нельзя; окончательное удаление без подтверждения невозможно.
- [ ] При сканировании тома сумма блоков (файлы + свободно + purgeable + снимки) равна ёмкости диска с точностью до 1%.
- [ ] Все команды из раздела 10 доступны и работают с указанными клавишами.
